# 未见受试者校准器迁移：文献依据与实验边界

核查日期：2026 年 11 月 9 日。本文记录实验设计和作者公开实现的对应关系，不包含本次实验结果。训练状态和指标以运行目录中的配置、日志及结果文件为准。

## 本次要回答的问题

本次检验：主模型从未用 S1、S2 做任务训练时，在其中一位受试者上学到的特征修正规则，能否迁移到另一位受试者；身份监督是否有助于这种迁移。

两种主模型都只在 S3—S10 上训练，差别是有无身份监督。正常源受试者训练沿用原始检索路径，不经过校准器 C。主模型训练完成并冻结后，再在模拟新受试者分支训练 C。真实新受试者推理时启用这条分支。

这里的“未见”指本项目的任务训练、验证和模型选择均未使用 S1、S2。原始 REVE 基础模型的预训练数据暴露情况需要独立核对，不能仅凭本次受试者划分推断。

## 三项相关工作

| 工作 | 原论文的方法 | 目标受试者支持集 | 本次可借鉴的部分 |
| --- | --- | --- | --- |
| MLDG，AAAI 2018 | 在源域内划分 meta-train 和 meta-test；先计算一次训练更新，再优化更新后的跨域表现 | 部署时不需要目标支持集 | 以受试者为域构造训练／验证任务，明确内外层更新 |
| Episodic-DG，ICCV 2019 | 交叉组合共享模块与其他源域的特定模块，模拟特征提取器和分类器之间的域不匹配 | 部署时不需要目标支持集 | 将正常训练路径与模拟域变化的辅助路径分开，明确各模块更新范围 |
| META-EEG，ESWA 2024 | 以源受试者构造元学习任务，结合分类头更新控制，学习零校准 EEG 分类表示 | 零校准评估不使用目标受试者标注；代码中的支持数据来自源受试者 | EEG 的受试者级任务组织，以及表示与分类头的分开更新 |

### MLDG：跨域更新目标

Li 等的 [Learning to Generalize: Meta-Learning for Domain Generalization](https://arxiv.org/abs/1710.03463) 将部分源域视为模拟未见域，优化模型在其他源域更新后的表现。它训练的是能够直接部署的域泛化模型。[作者代码](https://github.com/HAHA-DL/MLDG)提供了这一内外层目标的实现。

已核查版本：`19134860db3b02b511ea682d1cd353350322602f`。

| 文件／函数 | 实现内容 |
| --- | --- |
| [model.py：ModelMLDG.train](https://github.com/HAHA-DL/MLDG/blob/19134860db3b02b511ea682d1cd353350322602f/model.py) | 随机选择源域作为 meta-validation，计算 meta-train 损失和更新后的 meta-validation 损失 |
| [ops.py：linear、conv2d](https://github.com/HAHA-DL/MLDG/blob/19134860db3b02b511ea682d1cd353350322602f/ops.py) | 用梯度构造临时更新参数，支持保留二阶计算图或停止该梯度路径 |
| [mlp.py：MLP.forward](https://github.com/HAHA-DL/MLDG/blob/19134860db3b02b511ea682d1cd353350322602f/mlp.py) | 将元学习损失和步长传入功能式网络层 |

作者示例使用旧版 PyTorch 和 PACS 图像特征。本次借鉴“用源域模拟未见域”的设计思想，没有移植其完整元梯度目标。冻结主模型后，只在一位新受试者上训练 C，再迁移到另一人，不构成 MLDG 的内外层跨域训练。

### Episodic-DG：正常路径与模拟路径分开

Li 等的 [Episodic Training for Domain Generalization](https://arxiv.org/abs/1902.00113) 训练共享网络及源域特定模块，通过跨域组合模块制造不匹配，要求共享网络处理这种变化。部署时使用统一网络。[作者代码](https://github.com/HAHA-DL/Episodic-DG)明确区分了域特定网络和聚合网络。

已核查版本：`7cbdae5bc469b2b95b0f16be6797a70548e3d4fa`。

| 文件／函数 | 实现内容 |
| --- | --- |
| [PACS/model_resnet.py：ModelEpiFCR.train_ds_nn](https://github.com/HAHA-DL/Episodic-DG/blob/7cbdae5bc469b2b95b0f16be6797a70548e3d4fa/PACS/model_resnet.py) | 更新源域特定网络 |
| 同文件：`ModelEpiFCR.train_agg_nn` | 训练共享网络，组合正常分类损失与 Epi-F／Epi-C／Epi-R 损失 |
| [PACS/resnet_epi_fcr.py](https://github.com/HAHA-DL/Episodic-DG/blob/7cbdae5bc469b2b95b0f16be6797a70548e3d4fa/PACS/resnet_epi_fcr.py) | 定义域特定网络、共享网络及其前向路径 |

本次复用的是分支职责和参数更新范围的设计原则。原论文会通过 episodic 目标更新共享主模型；本次在普通源训练结束后冻结主模型，仅训练 C，因此属于独立的后置校准实验，不复现 Epi-F／Epi-C／Epi-R 的完整训练目标。

### META-EEG：EEG 受试者级元学习与代码核查

Han 等的 [META-EEG: Meta-learning-based class-relevant EEG representation learning for zero-calibration brain–computer interfaces](https://www.sciencedirect.com/science/article/pii/S0957417423024880) 发表于 Expert Systems with Applications，第 238 卷，文章 121986，2024 年；DOI 为 `10.1016/j.eswa.2023.121986`。该工作的证据来自运动想象 EEG 分类，任务与本项目的开放图片检索不同。

[作者代码](https://github.com/MAILAB-korea/META-EEG)已核查版本：`f3e92b94144df740fb6864186f6ead6df6fcf75d`。

| 文件／函数 | 实现内容 |
| --- | --- |
| [data_generator.py：task_generator](https://github.com/MAILAB-korea/META-EEG/blob/f3e92b94144df740fb6864186f6ead6df6fcf75d/data_generator.py) | 按源受试者数据块构造 support／query 任务，代码包含特定数据集的固定试次数 |
| [main.py：main](https://github.com/MAILAB-korea/META-EEG/blob/f3e92b94144df740fb6864186f6ead6df6fcf75d/main.py) | 使用 `higher.innerloop_ctx` 执行可微内层更新，并控制分类头的更新周期 |

公开实现需要先检查运行可靠性。上述固定版本的 `main.py` 第 83—85 行在 `torch.no_grad()` 内将 `outer_loss` 累计到初始不含梯度的 `total_loss`，第 90 行随后调用 `total_loss.backward()`。按 PyTorch 的计算图规则，这条路径存在外层梯度未被记录的风险。这是对该版本代码的静态检查，未在作者完整环境及真实数据上复现运行，不能据此判断论文结果。另外，第 170—171 行使用随机数据占位，复现必须接入真实 EEG。

本次可以参考其受试者级任务组织，不能直接复制未核验的训练循环。分类标签也需要替换为本项目的图像检索目标；运动想象分类成绩不能作为本项目校准效果的数值基线。

## 固定 pilot 与 seen_source 对照

两种监督主模型分别训练，但都只使用 S3—S10。主模型的 checkpoint、EMA 及超参数选择仅依据源受试者验证数据。主模型冻结后，按下表独立训练校准器。

| 条件 | C 的训练来源 | 评估来源 | 目的 |
| --- | --- | --- | --- |
| 无校准 | 不训练 C | S1、S2 | 保留原检索能力作为零校准基线 |
| novel，方向 A | S2 | S1 | 检验在主干未见受试者上学到的修正规则能否迁移 |
| novel，方向 B | S1 | S2 | 检验反向迁移是否一致 |
| seen_source，配对控制 | S3—S10 | S1、S2 | 检验相同模块在主干已见受试者上训练时的迁移效果 |

两个 novel 方向各有独立的 C。无身份监督与身份监督主模型各自配套训练 C，参数量、训练预算、初始化种子与样本清单保持配对。这里的“共享校准器”指一份 C 可应用于训练它时未见的目标受试者，不是将 S1、S2 合并训练后再对二者评估未见受试者泛化。

所有 C 使用相同的 14,886 张拟合图片和 1,654 张开发图片，二者图片身份互斥，并排除原始 200 张测试图片。每张图片只使用一条真实 EEG，种子固定为 33—37。novel 条件从对应的 C 训练受试者中选取这一试次；seen_source 条件在八位源受试者中按图片随机选择一位，再选择一条真实试次。seen_source 总计仍是每图一条 EEG，不扩成八倍训练量，也不平均为伪试次。所选受试者、试次和图片清单应落盘，供两种监督主模型共享。

C 的选择只依据其训练来源中的开发图片：novel 使用该方向 C 训练受试者的开发图片，seen_source 使用源受试者控制清单中的开发图片。目标受试者测试成绩不参与选参数、选步数或选 checkpoint。两方向和所有种子的测试结果都保留，不能依据其中一人结果再为另一人调整配置。

seen_source 与 novel 保持图片、样本数量和模型容量一致，但前者涵盖八位受试者，后者每个方向只有一位。因此这个控制同时涉及主干是否见过这些受试者和 C 训练数据的受试者多样性。若两者有差异，不能仅凭这组结果把原因完全归于“主干是否见过”。

## 推理接口与梯度边界

当前 C 若只读取当前 EEG 的 512 维表示，即 `C(e)`，新受试者无需额外支持集或在线参数更新。它是预先学好的特征修正函数。如果后续增加目标受试者均值、协方差或其他跨试次上下文，应另立条件，明确统计量来自独立无标签校准集还是测试集；这会改变部署协议。

主模型普通源训练不通过 C。训练 C 时冻结 REVE、原投影头及图像 adapter，并保持冻结网络的运行统计不变；只更新 C。零初始化后，C 分支应复现原模型输出。两种监督模型分别使用各自原生冻结 blur 图像 adapter，不在模型间交换视觉候选空间。

报告同时列出无校准和加 C 后的单试次、聚合 Top-1／Top-5，以及两种监督模型的绝对差值。聚合沿用同人同图全部有效试次先推理、再平均原始预测的方式。不能用起点较低带来的更大增量替代最终检索优势。

## 结果能够回答的范围

这项实验可以检验：同样的后置校准器在身份／无身份主模型上是否表现不同，以及在一个任务训练未见受试者上训练的 C 能否跨人迁移。每个 novel 方向只有一位 C 训练受试者，因此尚未形成 MLDG 式多源域 episode 或完整元学习训练。将同一人的试次划成拟合／开发集，也不会增加跨受试者任务数量。

S1、S2 已用于此前的开发实验，本次以重新训练、严格排除二者的主模型修正训练暴露问题；结果应称为固定协议下的双向开发验证。是否具备更广泛的跨人适用性，需要在配置锁定后增加受试者方向验证。

## 本次实现及固定设置

校准器作用于 REVE 的 512 维池化表示：`e' = e + Linear(64,512)(GELU(Linear(512,64)(LayerNorm(e))))`。末层权重和偏置初始化为零，新增 67,136 个可训练参数。随后沿用各自原投影头、B 组恢复头和冻结图像 adapter。源模型训练绕过校准器；训练校准器时，梯度经过冻结的检索头返回校准器，原模型权重不更新。

| 阶段 | 固定配置 | 选择规则 |
| --- | --- | --- |
| 源模型 | 原始 REVE 预训练权重；检索头重新初始化；S3—S10；batch 256；AdamW，REVE／头学习率均为 1e-4，weight decay 0.05；OneCycle；最多 40 轮，patience 5 | 源受试者的 1,654 张未参与拟合图片，blur 单试次 Top-5；比较 Raw 与 EMA .999／.9998 |
| 源模型两组差别 | 一组无身份损失；一组在 pooled512 上加入身份对比损失，权重 1.0，温度 0.1 | 相同初始化、数据划分和训练配置 |
| 校准器 | 每个池每图一条真实试次；14,886 图拟合，1,654 图开发；AdamW，学习率 3e-5，weight decay 0.01；batch 256；最多 20 轮，patience 5；梯度裁剪 1 | 校准器训练来源的开发集 blur 正确图片平均排名最小；并列保留较早轮次；允许保留零步原模型 |
| 校准损失 | 单向 clean CE ＋ blur CE，等权；仅图像目标归一化，温度为 1；校准时关闭数据增强和所有冻结头的 Dropout | 测试指标不参与选择 |
| 重复与评估 | 每种源模型的 seen／novel01／novel02 各用种子 33—37，共 30 个校准器；两人各 200 张测试图、16,224 条有效试次 | 同时报告 clean／blur 单试次与先预测后平均的聚合 Top-1／Top-5 |

源训练保留现有的同人同图混合试次、通道遮挡及 Local OT 配方。校准器训练使用真实单试次，以便单独观察校准模块的作用。代码入口分别为 `run_unseen_source.py`、`train_unseen_calibration.py`；`queue_unseen_calibration.py` 只在没有计算进程的 GPU 上依次执行预检、源训练和校准，不终止已有任务。
