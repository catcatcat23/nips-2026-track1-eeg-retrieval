# Frozen recovery-head ablation

Run A/B/D from the same pinned v13 epoch-7 representation. REVE, EEG blur projection and image adapter are not updated. A and B retain the original one-way, y-normalized clean ClipLoss (including its diagonal-positive semantics). D deliberately changes the loss: unit-normalized CE at 0.07 with unique image-ID gallery, cosine direction 0.1, teacher-clean similarity KL 0.1 (both soft temperatures 0.1, no temperature-squared scaling). Thus B vs D tests the full loss bundle, not an isolated KL term.

A has a freshly initialized old residual head. B/D have identical freshly initialized projected-head weights. Do not compare one newly initialized head to a warm-start head. Original v13 head is evaluated separately and must reproduce its saved result. All arms use seed33, deterministic frozen FP32 features, same dedicated-generator shuffled order, batch256, AdamW 1e-4/wd0.05, OneCycle40 epochs/pct_start0.1, patience5, gradient clip1. Public test single-trial Top5 selects checkpoints as explicitly requested by user; scores are model-selection results, not independent test evidence. Test IDs never enter optimizer steps. Both official raw-output metrics and per-subject metrics are recorded. No output unit-normalization is inserted before official aggregation.

Run order: CPU compilation/config checks; eight real training samples overfit plus batch256 gradient smoke; extract float32 h once for train/val/test; A/B/D train on GPUs1/2/3. GPU0 v14 remains untouched. A uses GPU1 first to replay original metrics. Cache source SHA256 is validated before extraction. Cache completion marker appears only after all splits finish. Failure retains logs and partial files, and refuses silent overwrite.

Proposal references: MindEye2 https://arxiv.org/html/2403.11207v1 (residual MLP and SoftCLIP); relational distillation https://arxiv.org/abs/1904.05068 (motivation only, not its exact RKD equations). These are proposed adaptations, not published EEG performance claims. This is a head-only diagnostic, not end-to-end fine-tuning or a submission package.
