### 结论

1. **同一套配方在两个数据集上都有效。** 迁移到 Alljoined2025 时没有调任何超参数，聚合 Top5 提高了 12–14 个点。
2. **EMA 是稳定有效的组件。** 和 raw 权重相比，单试次 Top5 高约 1.3–4 个点，聚合 Top5 高约 5–10 个点。
3. **没有采用的方案：**
   - SWA（对第 7–11 个 epoch 的 EMA 权重取平均），和最好的单个 EMA checkpoint 相差不到 0.3 个点；
   - 在 stage1 的 EMA 权重上继续训 stage2，单试次低 1.5–2 个点。
4. **限制：**
   - checkpoint 都是在 public test 上选的，属于开发集结果，不是独立测试或平台分数；
   - 两个数据集都只跑了 seed33；
   - 训练在第 11–15 个 epoch 就早停了，而 OneCycle 是按 40 个 epoch 设计的，学习率还没退火。

每个 epoch 的完整指标见 `evidence/things_v64_history.jsonl` 和 `evidence/alljoined_v67_history.jsonl`。

## 模型架构

```
EEG [B,C,120] → 线性插值到 200 点 → 逐通道 z-score（clamp ±15）
  → REVE-base（brain-bzh/reve-base，全参数微调） → token 均值 → Linear(512→1536) = h        （blur 空间）
  → ProjectedHead：LN → Linear → 2×ResidualBlock → LN → Linear = z  （clean 空间，推理输出 [B,1536]）

只在训练时使用的分支：
  blur 图像特征 → image adapter：Linear(1536→768) → ELU → Dropout(.2) → Linear(768→1536) = a
  REVE tokens → LN → Linear(512→256) → 6 个可学习 query 做注意力 = q
  图像 3×3 区域 token → Linear(1536→256) → GELU → LN，加上位置编码 = v
```

- **损失**：`ClipLoss(z, clean) + ClipLoss(h, a) + 0.1 × LocalOT(q, v)`。
  - ClipLoss 是单向的，只对图像侧做归一化，温度固定不学习。
- **Local OT**：
  - 每条样本选 5 个图像区域、3 个 query，做 6 次迭代的 Sinkhorn，ε=0.1；
  - 正样本按同一张图判定（multi-positive），每条样本配 31 个困难负样本，双向对比；
  - 各区域的权重按被试分别计算：用训练集 EEG 做 5 折 Ridge 回归，看每个区域的可预测性（`src/local_ot_weights.py`）。
- **增强**：
  - 混合试次：同一被试、同一张图的试次，以 50% / 25% / 25% 的概率分别取 1 / 2 / 4 条做平均；
  - 通道遮挡：20% 的样本随机把 1 个通道置零。
- **EMA**：每次优化器更新后同步更新 0.999 和 0.9998 两份权重，不参与训练。
- **优化**：
  - AdamW，编码器和检索头的最大学习率都是 1e-4，weight decay 0.05；
  - OneCycle 调度，40 个 epoch，pct_start=0.1；
  - batch 256，梯度裁剪 1，FP32 计算，关闭 TF32，seed33。
- **选模型与早停**：每个变体（raw / EMA0.999 / EMA0.9998）按 Blur 单试次 Top5 各自选最佳 epoch；如果连续 5 个 epoch 三个变体都没有提升，就停止训练。
- **推理**：只保留 encoder + blur_head + recovery，输入 EEG，输出原始的 `[B,1536]`，不需要图像，也不跑 OT。

# 多受试者 EEG 图像检索：阶段工作与实验分析

汇报日期：2026 年 11 月 1 日

研究重点：重复试次增强、模型参数平均，以及不同 EEG 数据集上的共享检索模型。

## 一、研究目标与目前进展

本项目研究如何从 EEG 中识别受试者正在观看的图片。模型输入一条 EEG，输出一个 1536 维向量，再与候选图像的 DINOv2 特征比较，选出最匹配的图片。当前目标是训练一个可以供多位受试者共用的模型，并在 THINGS-EEG2 与 Alljoined2025 两个数据集上检验其表现。

实验中遇到的主要问题是：单试次 EEG 的预测不够稳定；模型在经过图像 adapter 变换的特征空间中检索较好，但转换到比赛要求的固定 clean 空间后，成绩会下降；训练后期的单试次与聚合指标也不总是同步改善。围绕这些问题，已完成数据与评估流程核查、模糊图像监督迁移、恢复头对照、重复试次增强、EMA 对照以及两数据集联合训练。

目前较有价值的发现是：同人同图的混合试次训练在 THINGS 上改善了单试次和聚合检索；EMA 在两个数据集的同轮对照中均带来收益；单纯扩大恢复头没有稳定超过较简单的残差网络。通道掩码的独立收益还不充分，增强与 EMA 的交互作用、跨受试者混合的效果正在进一步检验。

| 已完成的工作 | 针对的问题 | 当前得到的认识 |
|---|---|---|
| 核查数据配对、图像缓存与官方评分 | 不同处理流程和评估口径使成绩难以比较 | 明确区分 clean／blur、单试次／输出聚合，以及开发集成绩／独立测试成绩 |
| 迁移 DINOv2、图像 adapter 与恢复头 | EEG 容易对齐的空间与比赛输出空间不同 | adapter 在原仓库对照中有作用；恢复头单独训练在部分主干上有效 |
| 比较不同恢复结构与第一阶段 checkpoint | blur 检索较好，但 clean 恢复不足 | 增大网络不一定有效；第一阶段表示的选择会影响恢复结果 |
| 同人混合试次、通道掩码与噪声对照 | 单试次预测不稳定 | 混合试次有正面证据；掩码和噪声的额外收益较小且依赖指标 |
| Raw 与 EMA 配对评估 | 最终成绩受训练权重波动影响 | EMA 在当前两个数据集配方中有效，但不能直接解释为 EEG 专属去噪 |
| THINGS 与 Alljoined 联合训练 | 一个模型需要兼容两套采集布局 | 使用 REVE 原生位置编码可以共享模型，性能接近或部分优于分开训练 |

## 二、任务、数据与评估方式

### 2.1 数据设置

当前实验使用 THINGS-EEG2 和 Alljoined2025，后者也称 Alljoined-1.6M。两者共享训练与测试图片范围，但 EEG 采集布局、受试者和信号分布不同。当前评估中的受试者均在训练阶段出现过，测试图片则未参与训练，因此这里检验的是“已知受试者对未见图片的检索”，不是未见受试者泛化。

| 项目 | THINGS-EEG2 | Alljoined2025 |
|---|---:|---:|
| 受试者数量 | 10 | 20 |
| 模型读取通道数 | 63 | 32 |
| 预处理缓存 | 120 Hz，每试次 120 点 | 120 Hz，每试次 120 点 |
| 当前联合实验训练缓存条数 | 668,400 | 1,335,616 |
| 当前测试缓存条数 | 162,240 | 324,294 |
| 训练图片数量 | 16,540 | 16,540 |
| 测试图片数量 | 200 | 200 |
| 训练数据组织 | 原 train 与 val 合并 | 原训练图片对应数据 |

两域的训练图片与测试图片不重叠。模型内部保留当前 REVE 输入适配：将缓存信号插值到 200 个时间点，逐通道标准化，并截断至正负 15。该适配与缓存中的官方预处理属于不同环节。

### 2.2 指标含义

| 指标 | 计算方式 | 用途 |
|---|---|---|
| clean 单试次 | 每条 EEG 独立推理，与官方 clean 候选检索 | 比赛空间中的单次预测能力 |
| clean 聚合 | 同人同图的原始预测取平均，再归一化、检索 | 比赛空间中的多试次聚合能力 |
| blur 单试次 | 中间预测与经过 adapter 的模糊图像特征检索 | 分析中间空间的对齐效果 |
| blur 聚合 | 同人同图的中间预测平均后检索 | 分析中间空间的聚合效果 |

官方聚合发生在模型输出之后，不是先将 80 条 EEG 平均后输入模型。聚合使用同人同图的全部有效预测，代码没有规定每组必须恰好包含 80 条。后文每格“Top-1／Top-5”的单位均为百分比；200 候选下的随机水平为 0.5%／2.5%。[官方评分实现](https://github.com/neural-interfaces26/2026-competition/blob/main/tracks/image_decoding/objective.py)

后期多组实验使用公开测试集进行 checkpoint 选择和早停，因此下述成绩属于开发阶段结果。它们可以用于内部诊断，但正式论文还需要验证集选模和未参与方案选择的数据，才能支持独立泛化结论。

## 三、模型构建与恢复问题的定位

### 3.1 从原仓库复现到比赛模型

首先在原仓库协议下固定 EEG 网络，比较图像编码器与 adapter，避免同时更换所有模块。该对照使用单受试者 sub-01、seed21、原仓库平均试次设置、batch1024、学习率 0.001、200 轮训练。

| 原仓库对照 | Top-1 | Top-5 |
|---|---:|---:|
| CLIP RN50＋图像 adapter | 81.00% | 96.00% |
| DINOv2＋图像 adapter | 87.50% | 98.50% |
| DINOv2，去掉图像 adapter | 60.00% | 91.50% |

这组结果表明，DINOv2 在原协议下可以正常拟合，adapter 对该设置中的对齐有较大影响。不过，单受试者平均输入协议与后来的多人比赛协议不同，不能把这里的成绩与比赛单试次结果直接比较。

比赛要求输出对齐固定的官方图像空间，而不能在推理时自行改变候选图像特征。为保留 adapter 的训练作用，同时满足比赛接口，后续模型采用以下结构。

```text
EEG → REVE → token 均值池化 → 线性投影 h → 恢复头 → clean 预测
                                     ↑
                           对齐 adapter（blur 图像特征）

训练辅助：REVE tokens 与图像局部区域之间的 Local OT 对齐
推理保留：EEG → REVE → 投影 → 恢复头
```

图像侧使用 12 个尺度的模糊特征，先逐尺度归一化，再取平均，经过可训练的图像 adapter 后作为中间对齐目标。官方 clean 特征独立保留。训练时同时约束中间表示对齐 blur 目标、最终输出对齐 clean 目标；Local OT 作为局部匹配辅助损失，不参与最终检索重排序。

早期图像缓存的模糊、缩放和归一化顺序与参考实现不一致，后续已按照参考流程修正。这属于复现和工程校正，不应作为算法贡献。Local OT 也是从已有方法迁移的模块，其独立收益仍需在相同增强和 EMA 配置下补充开关对照。

### 3.2 二阶段恢复有效，但扩大网络不是持续提升的来源

恢复实验先冻结已经训练好的 REVE 与 EEG 投影，只更新恢复头，以区分主干表示和恢复网络的作用。典型配置为 batch256、AdamW 学习率 0.0001、weight decay 0.05、OneCycle40、早停 patience5、FP32。

| 实验与改动 | clean 单试次 | clean 聚合 |
|---|---:|---:|
| v33：联合训练得到的模型 | 17.37／42.20 | 57.45／87.90 |
| v38：冻结 v33，单独训练恢复头 | 18.00／43.06 | 64.60／91.55 |
| v39-B：Ridge 映射＋残差修正 | 17.73／42.50 | 66.35／93.05 |
| v45：去掉 Ridge，保留可训练恢复网络 | 17.69／42.45 | 66.40／92.95 |

在这一主干上，二阶段训练将 clean 聚合 Top-5 从 87.90% 提高至约 93%。去掉 Ridge 后只下降 0.10 个百分点，说明没有足够证据认为固定 Ridge 映射是主要收益来源。进一步加深、加宽、引入门控、U-Net 样式结构或 token 条件 Transformer，没有稳定超过 v45；条件扩散的该次实现也未获得可用的恢复表现。这些结果将研究重点从“持续扩大恢复网络”转向“第一阶段学到了什么表示”。

### 3.3 第一阶段权重的选择会影响恢复效果

| 第一阶段权重 | blur 单试次 | blur 聚合 | 同样 v45 式二阶段后的 clean 单试次 | 二阶段 clean 聚合 |
|---|---:|---:|---:|---:|
| v57 第18轮 | 17.48／42.05 | 84.50／98.45 | 14.98／36.77 | 65.45／90.65 |
| v57 第9轮，进入 v60 | 19.45／45.17 | 77.90／96.50 | 17.34／41.42 | 67.85／93.40 |

第18轮的 blur 聚合成绩更高，但第9轮的单试次成绩更好，进入相同二阶段后，clean 聚合 Top-5 反而高 2.75 个百分点。因此，仅按 blur 聚合最高分选择主干，不能保证最终 clean 恢复最好。

在第18轮表示上加入聚合监督、一致性约束和教师蒸馏后，clean 聚合 Top-5 仍约为 90.65%～90.80%。改用第9轮表示后，三个恢复头训练种子的结果为 93.40%、93.70% 和 93.55%。这支持权重选择的重要性，但三个种子仅重复恢复头训练，不能当作完整模型多种子验证。

## 四、主要改进一：利用重复试次进行训练增强

### 4.1 实现方式与对照设置

混合试次训练让模型同时接触原始 EEG 和部分平均后的 EEG。每个锚点以 50% 的概率保留单试次，以 25% 的概率取同人同图的两条试次平均，以 25% 的概率取四条平均。额外试次从训练数据中无放回选择，始终包含锚点；数量不足时使用实际可用数量。平均发生在 REVE 内部标准化之前，监督图片不变。

在此基础上，分别加入通道掩码或高斯噪声。通道掩码对 20% 的样本随机将一个完整通道置零，而不是遮挡 20% 的通道；噪声对照在标准化后对 20% 的样本加入标准差为 0.02 的高斯噪声。测试阶段关闭增强。这里的 EEG 噪声与图像侧高斯模糊是不同操作。

为了减少不同选模轮次的影响，下表统一使用 THINGS 第10轮 Raw 权重。各组共同使用 REVE、clean＋blur 监督和 Local OT，seed33、batch256、AdamW 最大学习率 0.0001、weight decay 0.05、OneCycle40、FP32，图像 adapter dropout 为 0.2。相同轮次并不代表历史实验随机流完全相同，正式复验仍需统一初始化和数据顺序。

### 4.2 增强结果

| 实验及变化 | clean 单试次 | clean 聚合 | blur 单试次 | blur 聚合 |
|---|---:|---:|---:|---:|
| v53：无 EEG 增强 | 15.56／39.06 | 58.90／88.70 | 17.75／42.92 | 77.75／96.80 |
| v55 mixed：加入同人混合试次 | 17.23／41.17 | 63.35／90.25 | 19.38／45.28 | 79.95／97.15 |
| v55 noise：mix＋高斯噪声 | 16.88／40.85 | 62.40／90.35 | 19.04／44.90 | 79.95／97.45 |
| v57：mix＋通道掩码 | 17.16／40.98 | 63.65／90.25 | 19.38／45.17 | 79.75／97.50 |

混合试次相对无增强，clean 单试次 Top-5 提高 2.11 个百分点，聚合 Top-5 提高 1.55 个百分点；blur 单试次和聚合 Top-5 分别提高 2.36 和 0.35 个百分点。这说明在当前设置中，训练时加入平均试次并未牺牲单试次预测，反而同时改善了两类评估结果。

通道掩码相对只用 mix，clean 聚合 Top-5 不变，blur 聚合 Top-5 提高 0.35 个百分点，但 clean 单试次 Top-5 下降 0.19 个百分点。高斯噪声也表现为单试次略降、部分聚合指标略升。因此，现有证据对 mix 的支持较清楚，对掩码和噪声的额外收益则较弱，不能将它们写成已经得到充分验证的独立贡献。

混合试次可能减少试次波动，但性能变化尚不能证明其作用仅为去噪。按当前比例，每个锚点理论上平均接触两条原始 EEG，数据使用量也发生了变化。后续需要匹配试次接触次数的对照，区分平均操作和额外数据暴露的作用。现有表格也只覆盖 THINGS，尚不能直接推广到 Alljoined。

## 五、主要改进二：用 EMA 改善推理权重

### 5.1 同一训练轨迹上的配对结果

EMA 是模型参数的指数移动平均：每次优化器更新后，将上一份 EMA 参数与当前 Raw 参数加权平均，作为另一份推理权重。它不参与反向传播，也不会改变 Raw 模型的优化过程。因此，同一轨迹、同一轮的 Raw／EMA 比较，能够较直接地检验参数平均的效果。

| 数据集与轮次 | 推理权重 | clean 单试次 | clean 聚合 | blur 单试次 | blur 聚合 |
|---|---|---:|---:|---:|---:|
| THINGS，v64 第10轮 | Raw | 16.71／40.77 | 62.30／90.30 | 18.92／44.80 | 80.50／97.75 |
| 同上 | EMA 0.9998 | 19.76／45.58 | 69.80／93.95 | 22.35／49.72 | 86.65／98.60 |
| Alljoined，v67 第6轮 | Raw | 3.27／11.94 | 19.28／47.95 | 3.57／12.57 | 28.35／58.45 |
| 同上 | EMA 0.9998 | 3.79／13.22 | 24.43／54.30 | 4.05／13.85 | 38.15／68.95 |

THINGS 的 clean 单试次和聚合 Top-5 分别提高 4.81 和 3.65 个百分点；Alljoined 分别提高 1.28 和 6.35 个百分点。两组结果支持 EMA 在当前训练配方中有效，但尚需与无增强基线比较，判断增强是否在 EMA 之上继续提供独立收益。

### 5.2 EMA 收益是否只是预测范数变化

预测范数是输出向量的数值大小。直接平均预测时，大范数试次对平均方向影响更大。为检验这一因素，诊断实验先将每条预测归一化，再执行聚合，与官方顺序比较。

| v69 第15轮，clean 聚合 Top-5 | Raw | EMA 0.9998 |
|---|---:|---:|
| THINGS：先平均预测，再归一化 | 90.20% | 94.05% |
| THINGS：逐试次归一化后再平均 | 90.30% | 94.10% |
| Alljoined：先平均预测，再归一化 | 46.15% | 58.73% |
| Alljoined：逐试次归一化后再平均 | 43.73% | 56.38% |

改变范数权重后，EMA 优势仍然保留。因此，聚合时的范数权重不能充分解释 EMA 的收益。Alljoined 逐试次归一化后反而下降，说明也不能将范数一概视为无用噪声。

普通参数平均同样有收益：v69 的 THINGS clean 聚合 Top-5 从末轮 Raw 的 90.20%，提高到第13～15轮 Raw 参数均匀平均后的 92.80%，EMA 为 94.05%。由于两种平均覆盖窗口不同，这还不能证明指数加权本身优于均匀平均。扰动实验中，EMA 的绝对成绩较高，但相对自身正常输入成绩的下降幅度并非总是更小，因而不宜将其解释为已经证实的 EEG 专属抗噪机制。

EMA 目前更适合作为强基线中的统一配置。论文应重点检验增强在相同 EMA 条件下是否仍有收益，而不是只将增强模型与未采用 EMA 的基线比较。

## 六、应用验证：一个模型联合训练两套通道布局

v69 共享 REVE、投影和检索相关模块，THINGS 使用 63 通道坐标，Alljoined 使用 32 通道坐标。每次更新顺序处理两域各 256 条样本，各自损失乘以 0.5 后累积梯度；对比学习仍在域内计算，不是将两域拼成 512 个图像候选。每轮处理一遍 THINGS 锚点，并从打乱的 Alljoined 数据中取相同数量，保持域间采样权重均衡。

| 数据与代表性模型 | clean 单试次 | clean 聚合 | blur 单试次 | blur 聚合 |
|---|---:|---:|---:|---:|
| THINGS 单独训练，v64 ep14 EMA | 18.81／43.89 | 70.45／94.90 | 21.51／48.15 | 88.75／99.00 |
| THINGS 联合训练，v69 ep15 EMA | 18.75／43.66 | 71.70／94.05 | 21.51／48.10 | 87.20／99.25 |
| Alljoined 单独训练，v67 ep8 EMA | 3.64／12.83 | 27.57／56.65 | 3.90／13.36 | 40.30／70.30 |
| Alljoined 联合训练，v69 ep15 EMA | 3.74／12.95 | 29.00／58.73 | 3.93／13.48 | 36.78／69.17 |

表中均使用 EMA 0.9998。联合训练使该对比中的 Alljoined clean 聚合 Top-5 提高 2.08 个百分点，THINGS 则下降 0.85 个百分点；blur 指标也并非全面提高。这说明共享模型可兼容两套布局并保持可用性能，但不同模型的训练预算和选中轮次不一致，尚不能据此证明联合训练带来普遍正迁移。

通道适配应明确归于 REVE 原论文的 4D 位置编码。本项目的工作在于正确组织原生通道输入、共享图片目标和域间训练，并评估共享模型的实际表现。[REVE 原论文](https://proceedings.neurips.cc/paper_files/paper/2025/hash/20a917f77773ac0fa8bea2bdd6606b66-Abstract-Conference.html)

### 7.2 区分“联合有效”与“存在协同”

v70 和 v71 的两次训练提供四种评估结果：无增强 Raw、无增强 EMA、增强 Raw、增强 EMA。首先比较增强 EMA 与无增强 EMA，回答增强在强基线上是否仍有效；再比较各增强条件下的 Raw 与 EMA，回答参数平均是否继续有用。

如果四种成绩依次记为 S00、S01、S10 和 S11，则额外交互量为 I＝S11−S10−S01＋S00。S11 最高只能说明联合使用表现最好；只有交互量为正且重复实验支持，才适合讨论超出单独收益相加的协同。接近100%的指标还存在天花板效应，需要同时报告原始成绩和错误率。

当前 v71 同时加入 mix 与 mask，不能分清二者各自的作用。完成现有实验后，应优先补齐以下对照，再考虑增加新网络结构。

| 条件 | mix | 通道掩码 | Raw／EMA | 要回答的问题 |
|---|---|---|---|---|
| A，v70 | 无 | 无 | 都测 | 原始基线 |
| B，待补 | 同人 | 无 | 都测 | mix 是否独立有效 |
| C，待补 | 无 | 有 | 都测 | mask 是否独立有效 |
| D，v71 | 同人 | 有 | 都测 | 两种增强组合及其与 EMA 的关系 |
| E，v72 | 跨人 | 有 | 都测 | 跨人平均是否优于同人平均 |
| F，必要时补充 | 跨人 | 无 | 都测 | 排除跨人 mix 与掩码的交互影响 |

A 至 D 的四次训练可形成 mix、mask、EMA 的八种评估组合。B、C、F 目前仅为计划，尚未提交。

### 7.3 跨受试者 mix 的实现与机制检验

v72 保留 50% 单试次、25% 两次平均、25% 四次平均的比例，但平均样本来自观看同一图片的不同受试者，每人取一个试次。混合包含锚点，仅在同一数据集和相同通道顺序内执行，不直接平均 THINGS 与 Alljoined 的 EEG。测试仍使用原始单试次。

跨人平均可能削弱个体相关差异，也可能抵消各人时间和空间上不同的有效反应。仅凭检索提高不能区分这两种作用，也不能证明模型学会了消除身份信息。因此，后续诊断应同时考察任务性能和表征中的身份信息。

| 诊断 | 实施方式 | 能回答的问题与限制 |
|---|---|---|
| 受试者身份探针 | 冻结模型，从池化表示、投影或输出训练身份分类器；图片划分不重叠 | 能否读出身份信息，但不能直接判断该信息有害 |
| 跨 session 身份探针 | 用不同采集 session 训练和测试探针 | 减少识别单次采集状态的可能，仍需考虑设备差异 |
| 同图身份匹配 | 部分试次建立每人的中心，其余试次识别人 | 控制图片差异后，受试者是否仍可区分 |
| 试次误差分析 | 比较同人／跨人同图的距离、检索间隔和错误相关性 | 分析聚合收益来源，不直接给出神经生理机制解释 |
| 留出受试者测试 | 测试对象完全不参与任务微调 | 才能支持新受试者泛化，还需审查预训练数据重叠 |

这些诊断尚未完成。当前跨人增强的数据检查只证明抽样和数组平均符合设计，不能替代效果验证。

## 八、可提炼的论文主线与尚需补齐的证据

目前最适合讨论的主线是：如何利用重复试次结构，提高多人 EEG 图像检索的单次预测与聚合表现，并检验这种增强在采用参数平均的强基线上是否仍有价值。恢复实验可作为问题定位过程，解释为何后续将重点从扩大恢复网络转向输入和训练稳定性；不必将所有尝试都写成独立贡献。

| 可讨论的方向 | 已有证据 | 论文表述边界 | 需要补充 |
|---|---|---|---|
| 同人混合试次训练 | THINGS 同轮多个指标改善 | 当前设置中的正面结果；不是已经证明普遍去噪 | mix-only、多seed、Alljoined对应对照、匹配数据接触预算 |
| 通道掩码 | 在mix基础上部分聚合指标略升 | 暂不能作为确定的独立贡献 | mask-only及其与mix、EMA的交互 |
| EMA参数平均 | 两域同轨迹同轮都有提升 | 有效训练策略；不是新算法，也不是已证实的EEG专属机制 | 无增强基线对照、匹配窗口的其他参数平均 |
| 联合训练 | 原生63／32通道共享模型可用 | 应用验证，位置编码属于REVE | 匹配样本与更新预算的单域比较 |
| 跨受试者mix | 已实现，尚无训练结果 | 待验证假设 | v72结果、身份探针和新受试者评估 |

正式实验需要先固定训练配方、主要指标和选模规则，再使用多个完整训练种子复验。建议至少三个种子，但不能据此保证统计功效充分。已有恢复头多种子不能替代主干多种子，测试抽样种子也不能当作独立训练重复。当前没有显著性检验或置信区间，报告只陈述观察到的差值。

评估应使用按图片划分的独立验证集选模，再在未参与方案选择的数据上测试。试次共享受试者和图片，统计分析不能把几十万条试次视为相互独立的样本，应考虑受试者、图片和训练种子的分组关系。同时需要记录训练预算、原始试次接触次数和停止轮次。当前 OneCycle 按40轮设计，却可能较早停止，因此不能将这些模型描述为完成了整个学习率退火过程。

最终是否能够形成方法贡献，应由上述对照决定。如果 mask 没有稳定收益，应如实保留这一结果；如果 mix 在 EMA 基线和两个数据集上仍有效，再围绕重复试次结构的利用展开论证。已有工作也使用了 EEG feature-level mixup 与身份对抗训练，本项目需要明确原始 EEG 同图平均与这些方法的区别，避免将已有策略重新命名为创新。[相关工作，SAC 2026](https://doi.org/10.1145/3748522.3779935)
