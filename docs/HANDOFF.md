# EEG 图像检索项目交接（2026-11-09）

## 接手目标

项目使用 EEG 预测图像特征。当前需要解释两件事：为什么试次混合与 EMA 提高检索成绩，以及为什么身份监督让受试者特征更容易分开，却没有带来稳定的新受试者适配收益。请先读本文、实验路线表及原始证据，再提出下一项实验，不要把已完成的负结果重新当成新方案。

## 模型与评估

主线为预训练 REVE 全参数微调。比赛 EEG 输入经过现有固定预处理进入 REVE，池化为 512 维，再投影到 1536 维 blur 表示。图像侧使用冻结的 DINOv2 多尺度模糊缓存及可学习 adapter；恢复头输出 clean 表示。训练包含 clean、blur 对比损失以及 Local OT 辅助损失。具体形状、权重、初始化和调度以运行 config 与源码快照为准。

THINGS 使用 63 通道，Alljoined 2025 使用原生 32 通道及对应电极坐标。联合模型分别处理两个数据集的 batch 后合并梯度，没有将 32 通道简单补成 63 通道。通道坐标能力来自 REVE，不是本项目提出的机制。

本地通常在原始 200 张测试图片的候选库上评估。单试次逐条推理；聚合指标对同人同图全部有效试次的原始预测求均值后检索。不是先平均 EEG 再推理，也不强制截成 80 条。输出均值与输入均值经非线性网络不等价。

blur 检索使用对应模型的图像 adapter 后的候选特征；clean 检索使用官方 clean 特征。两者的候选空间不同，blur 高分不能直接当作比赛提交成绩。比赛提交只提供 EEG→1536 维 clean 输出；需要目标候选库的 SATTC/SCORE 实验是本地传导式研究，不能直接照搬进该接口。

历史主线有使用公开测试指标选 checkpoint 的实验，应称开发集结果。LOSO 适配实验使用单独支持集与开发集；不得用历史公开测试选择方式替代其协议。少样本种子是配对重复，不是独立受试者。

## 已经得到的结果

下表中的百分数是代表性记录，非统一预算排行榜。详细逐轮结果见 evidence/runs，各行必须连同数据集、层级、轮次、Raw/EMA 一起使用。

| 对照 | 设置 | 观察 | 能支持的结论 |
|---|---|---|---|
| v53 → v55 mixed | THINGS，第10轮 Raw，无增强→同人同图试次混合 | clean 聚合 Top-5：88.70→90.25；blur：96.80→97.15 | 混合试次有收益；仍需控制原始试次曝光量 |
| v55 mixed → v57 | 同轮 Raw，再加通道遮挡 | clean 聚合 Top-5：90.25→90.25；blur：97.15→97.50 | 遮挡收益较小，不能写成所有指标提升 |
| v55 noise | 混合试次再加 EEG 高斯噪声 | clean 聚合 90.35；blur 97.45 | 未形成稳定额外收益；不同于图像高斯模糊 |
| v64 Raw → EMA .9998 | 第10轮，同一训练轨迹 | clean 单试次 Top-5：40.77→45.58，聚合：90.30→93.95 | EMA 是强基线配置 |
| v67 Raw → EMA .9998 | Alljoined，第6轮 | clean 聚合 Top-5：47.95→54.30；blur：58.45→68.95 | EMA 收益不局限于 THINGS |
| v64 单独 → v69 联合 | v64 ep14 / v69 ep15 EMA | THINGS clean 聚合 Top-5：94.90→94.05 | 联合训练保持接近成绩，不是全面提升 |
| v67 单独 → v69 联合 | v67 ep8 / v69 ep15 EMA | Alljoined clean 聚合 Top-5：56.65→58.73；blur：70.30→69.17 | clean 有改善，预算不同，不能单独归因于联合训练 |
| v57 ep18 → ep9 后训练恢复头 | 同类二阶段方案 | clean 聚合 Top-5：90.65→93.40，后者另两种子93.70、93.55 | blur 聚合最高的表示未必最适合 clean 恢复 |

## 身份监督与适配：当前最重要的负结果

v78 是额外身份头；v80/v84 是全局身份对比，权重分别为0.1/1；v81/v82 是同图内区分身份，权重0.1/1；v83 是同概念内区分身份。辅助分支使用额外采样时，训练曝光量也改变，不能全部归为损失设计。v85—v87 将三个粒度移到 Alljoined；v89 直接监督 blur 层。具体批次与作用层须读各 run 配置。

身份线性分类和可视化说明模型保留了身份信息，却不能证明这些信息有利于图片检索。原始 REVE 已有较高身份可辨识性；身份监督后聚类更集中，也可能只是增加稳定的人际偏移。t-SNE 图只用于展示；不能挑最分开的图片作为全局证据。高维聚类、图片信息与跨试次可靠性应分别测量。

v79 无身份监督十折 LOSO 已完成，blur 单试次宏平均 Top-1/5 为5.183/17.298，聚合为16.35/41.00。v91 身份监督完成 S1—S4，其余折按用户要求暂停，不能与十折均值直接比较。

少标签适配以 S1、S2 为开发对象，共同支持图片、每图一条 EEG，种子33—37。冻结后重训读出、512维残差适配、LoRA、均值/方差/协方差对齐、Ridge、残差 Ridge、配对旋转均已测试。适配本身经常有效，但身份模型未达到预定的跨人稳定优势标准。

## 最新 v93：训练时学习校准，测试只输入一条 EEG

源模型仅使用 S3—S10。冻结后在 pooled512 上训练零初始化残差校准模块，比较已见源人拟合与新捐赠受试者拟合；在另一个未见的人上测试。30个校准模块、40项评估已完成。

| 源模型 | S1 零校准→在S2学校准后 | S2 零校准→在S1学校准后 |
|---|---|---|
| 无身份监督 | 65.50→38.00 | 28.50→27.10 |
| 身份监督 | 58.50→36.90 | 30.00→28.20 |

指标为 blur 聚合 Top-5，校准后为五种子均值。捐赠人的开发排名改善，但另一个新人性能下降。说明本次残差校准没有学出可跨新人的通用修正。源人校准几乎不改变表现。这里是固定源编码器的跨人校准试验，不是完整 episodic/meta-learning；已见8人与新1人的数据组织也不同。

2026-11-09 修复了报告读取 checkpoint_sha256 字段错误。修复前把40项评估误标无效；并非训练本身失败。修复后的 calibration_report 是当前依据，旧报告和补丁留存。不要据旧汇总重复训练。

## 下一步应先回答什么

优先检验同人同图重复试次的稳定性，以及共同视觉读出能利用多少图片差异，而不是继续最大化身份聚类。使用相同模型层、相同测试样本，分别量化跨试次噪声、受试者偏移、图片差异及人×图片交互；同时检查高维近邻和真实检索成绩。避免用二维图形距离代替机制证据。

增强消融应补齐原始 EEG 曝光量和更新次数控制。若比较单试次与试次均值教师，先验证教师确实更准，再区分训练平均带来的信噪比变化与额外原始样本访问。EMA 与末轮参数平均应作为强训练基线，不单独包装成 EEG 特有创新。

若继续训练校准模块，先做捐赠人数量匹配的对照，再考虑源受试者轮流留出训练。现有 v93 失败不证明所有元学习不可行，也不支持立即扩大网络。

## 给接手 agent 的任务

先检查本仓库 evidence/handoff_inventory.json、docs/EXPERIMENT_MAP.md 和研究源码。核对每项结论对应的数据划分、特征层、聚合方式、checkpoint 与监督来源。将已证实结果、待检验解释、未触发实验分开。围绕“稳定的图片响应是否提高可迁移检索”查阅原论文及作者代码，给出最小、能区分竞争解释的实验，而非继续叠加模块。

执行前读取 AGENTS.md 与 STORAGE_POLICY.md。仅有 GitHub 时，可以审阅代码和历史证据；数据、预训练权重、实验 checkpoint 需要由项目持有人提供。禁止把本仓库的本地绝对路径直接当作另一台机器可用的路径。
