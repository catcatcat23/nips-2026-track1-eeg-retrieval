**EEG 图像检索：混合试次、通道掩码、EMA 与跨受试者增强实验分析报告**

版本：2026-10-31。范围：以已完成的 v53–v69 和正在执行的 v70–v72 为依据，整理可支持的论文主张、局限与后续实验。百分比来自本地结果记录；没有进行新的显著性检验，也没有把排队实验写成完成实验。

**一、研究问题与贡献边界**

本项目要解决的问题是：同一图片对应的单次 EEG 很不稳定，模型既要保留单试次可用于检索的信息，也要让重复试次的预测聚合后可靠，并适用于多位受试者。

本报告聚焦三个可检验的主张：

1. 同人同图的随机试次平均，作为训练增强，能否改善不做平均的单试次测试，以及官方输出聚合检索？
2. 在混合试次之外，随机通道掩码是否还能带来额外收益？
3. EMA 是否在无增强基线与增强模型中都有效；二者是各自提供收益，还是存在额外的交互收益？

跨受试者同图平均是后续假设：它可能削弱受试者相关干扰，也可能损失有用信号；当前没有训练结果，不预设其有效。

REVE 的电极坐标/时间位置编码和兼容不同电极布局的能力来自原模型，不属于本项目的新架构。REVE 原论文明确提出 4D 位置编码，支持不同长度与电极排列。[NeurIPS 2025 原论文页面](https://proceedings.neurips.cc/paper_files/paper/2025/hash/20a917f77773ac0fa8bea2bdd6606b66-Abstract-Conference.html)。本项目利用该能力进行 THINGS 与 Alljoined 联合检索训练，属于应用和迁移验证。

试次平均、通道遮挡、EMA 本身也不是新发明。不应宣称首次使用，尤其已有 EEG 语义检索工作结合 feature-level mixup 和 subject-adversarial learning；该方法不等于本项目的原始 EEG 同图平均，但必须在相关工作中区别。[SAC 2026 相关工作](https://doi.org/10.1145/3748522.3779935)。可争取的贡献是清晰、可复现的实验发现与针对重复试次结构的训练方案，而非模块名称本身。

推理逐条处理 EEG。官方聚合指标按同一受试者、同一图片平均**原始预测特征**，然后归一化、计算与候选图像的余弦相似度；不是先平均 80 条原始 EEG 再推理。按评测实际提供的有效试次数聚合，不强制截断到80。[官方评分实现](https://github.com/neural-interfaces26/2026-competition/blob/main/tracks/image_decoding/objective.py)

所有主要表格中每格为 Top-1 / Top-5（%），200候选随机水平为0.5%/2.5%。clean 是比赛空间；blur 是可学习 adapter 图像空间的内部诊断，不是可直接提交的比赛得分。不要把二者之差全部叫作“丢失的信息量”。

后期大量实验依据公开测试指标选择 checkpoint、早停，并反复用同一测试集合研究方案。这些是开发集结果，不能作为未接触测试集上的无偏性能估计。现有历史无法通过改名称消除选择偏差。

**三、混合试次与掩码具体如何实现**

同人混合：对每个训练锚点，先随机决定用1、2或4条试次。概率为50%、25%、25%。额外试次必须属于同一受试者、同一图片，从训练集无放回抽取，包含锚点；数量不足时取可用数量。平均发生在官方缓存 EEG 上、REVE 内部插值和标准化之前。目标图片不变，不做不同图片标签插值。

通俗地说：模型有时听一次“嘈杂的描述”，有时听几次描述的平均，同时仍保留一半单试次训练，避免只适应很干净的输入。

通道掩码：完成当前 REVE 输入适配后，对20%训练样本随机将一个完整通道置零，其余通道不动。没有把20%的通道全部删除，也不改变坐标列表。测试时关闭。其假设是减少模型对个别通道的过度依赖，但并不等同于模拟所有坏导联或设备缺失问题。

高斯噪声对照：在标准化后，20%样本加入标准差0.02的高斯噪声。它是 EEG 噪声增强，与图像侧生成 blur 目标的高斯模糊不同。

样本预算注意：理论上每个增强锚点平均读取 0.5×1+0.25×2+0.25×4=2 条 EEG。虽然每轮锚点数、更新数相同，但有效原始试次接触次数更多。因此，“收益只来自去噪”尚未被证明；需要匹配重复呈现/数据暴露预算的补充对照。

**五、checkpoint与恢复实验给出的关键约束**

| v57 stage1来源 | blur 单试次 | blur 聚合 | 相同v45式stage2的clean单试次 | stage2 clean聚合 |
|---|---|---|---|---|
| 第18轮 | 17.48 / 42.05 | 84.50 / 98.45 | 14.98 / 36.77 | 65.45 / 90.65 |
| 第9轮 → v60 | 19.45 / 45.17 | 77.90 / 96.50 | 17.34 / 41.42 | 67.85 / 93.40 |

第9轮进入stage2比第18轮clean单试次Top5高4.65点，聚合Top5高2.75点。不是单纯“blur最高的模型就最好恢复”。在第18轮表示上加入聚合监督/一致性/教师蒸馏，聚合Top5仍约90.65–90.80%。

第9轮同一冻结表示，stage2 seed33/34/35的clean聚合Top5为93.40/93.70/93.55%。这是恢复头随机性的重复验证，不是三个独立stage1种子，不能作为整套方法跨训练种子稳定性的证明。

这段历史应作为诊断结果：检索空间和模型选择指标会影响恢复结果。主论文不必把所有失败恢复结构都当作贡献，附录可列出。新的增强/EMA对照优先用直接clean预测，避免恢复头引入额外解释变量。

**六、EMA：已有收益明确，机制解释必须收敛**

EMA参数在每次优化器更新后按 θema←βθema+(1−β)θraw 更新；不参与梯度，不反馈到训练参数。当前主要β=0.9998，历史另保留0.999。参数做指数平均，位置等buffer从当前模型复制；不是多个试次的预测平均。

同轨迹、同轮的比较：

| 数据/轮次 | 权重 | clean 单试次 | clean 聚合 | blur 单试次 | blur 聚合 |
|---|---|---|---|---|---|
| THINGS v64 ep10 | Raw | 16.71 / 40.77 | 62.30 / 90.30 | 18.92 / 44.80 | 80.50 / 97.75 |
| 同上 | EMA .9998 | 19.76 / 45.58 | 69.80 / 93.95 | 22.35 / 49.72 | 86.65 / 98.60 |
| Alljoined v67 ep6 | Raw | 3.27 / 11.94 | 19.28 / 47.95 | 3.57 / 12.57 | 28.35 / 58.45 |
| 同上 | EMA .9998 | 3.79 / 13.22 | 24.43 / 54.30 | 4.05 / 13.85 | 38.15 / 68.95 |

clean Top5的EMA收益：THINGS单试次+4.81点、聚合+3.65点；Alljoined单试次+1.28点、聚合+6.35点。差值用显示值计算，原始精度见history。

这是较强的组件效果证据，但只说明EMA在当前配方有效。尚需纯baseline对照，判断是否同样有效，以及增强能否在EMA之上继续提供收益。

机制诊断（v69 ep15）：

| clean聚合Top5 | Raw | EMA |
|---|---|---|
| THINGS，官方先平均预测再归一化 | 90.20 | 94.05 |
| THINGS，逐试次归一化后再平均 | 90.30 | 94.10 |
| Alljoined，官方聚合 | 46.15 | 58.73 |
| Alljoined，逐试次归一化后聚合 | 43.73 | 56.38 |

EMA优势没有因消除试次范数权重而消失，因此范数权重不是充分解释。Alljoined逐试次归一化反而降低成绩，不能说范数普遍无用。

v69 THINGS clean聚合Top5：末轮Raw90.20%，raw第13–15轮均匀参数平均92.80%，EMA94.05%。这支持参数平均的一般收益，但普通平均与EMA覆盖窗口不同，不能宣称指数加权机制已被单独证明优越。

合成噪声/遮挡测试中EMA绝对成绩较高，但相对自身无扰动水平的退化幅度并非总是更小。因此现阶段建议写“参数平均改善训练后检索表现”，不写“EMA专门去除EEG噪声”。

blur比较还有额外限制：EMA同时改变图像adapter，候选库也随之变化；clean候选固定，适合优先用于机制归因。

**九、如何计算“叠加”和“协同”，不混用两个概念**

记同一数据集、同一指标、同一epoch的四个成绩为：

- S00：v70 Raw，无增强无EMA。
- S01：v70 EMA，无增强有EMA。
- S10：v71 Raw，有增强无EMA。
- S11：v71 EMA，有增强有EMA。

分别报告：

1. EMA基础收益 = S01−S00。
2. 增强基础收益 = S10−S00。
3. EMA条件下的增强收益 = S11−S01。
4. 增强条件下的EMA收益 = S11−S10。
5. 交互量 I = S11−S10−S01+S00。

S11最高只能说明联合使用表现最好；只有I为正且不确定性分析支持，才能说存在超出简单相加的正交互。Top5接近100%时还有天花板效应，交互量在百分点尺度上可能被压缩，应同时报告错误率和原始成绩，不据此否定所有互补性。

v72与v71比较的是跨人/同人混合范围，其他增强与EMA保持一致；分别比较Raw和EMA，不把两个checkpoint策略混在一起。

对EMA本身机制，可在相同时间窗口比较末轮Raw、均匀参数平均、EMA，并报告梯度/预测方向波动、范数和错误相关性。当前3轮均匀平均对长窗口EMA不是严格匹配对照。

**十一、跨人mix：怎样区分降噪与个体差异**

直观假设：同人平均主要减少该人的试次波动；跨人平均可能进一步弱化稳定的人际差异，但也可能抵消各人不同时间位置的有效信号。这是待检验假设，不是已知机制。

必须同时测检索和表征，而非只看一张t-SNE图：

| 诊断 | 做法 | 解释边界 |
|---|---|---|
| 身份线性探针 | 冻结模型，在池化表示/投影/最终输出上分类受试者；图片划分不重叠 | 高于随机表示可读出身份，不代表身份有害 |
| 跨session身份探针 | 训练session与测试session分开，按人平衡样本 | 尽量排除单次采集状态；若身份与设备绑定仍不能完全区分 |
| 同图身份匹配 | 同图每个人一部分试次作中心，另一部分试次识别人 | 控制图片差异，不把同一试次放两边 |
| 试次一致性 | 同人同图/跨人同图的距离、检索间隔，匹配试次数 | 范数归一化与不归一化都报告，避免只测缩放 |
| 预测误差相关性 | 看多试次错误是否同步、是否容易互相抵消 | 解释聚合优势，不等价于神经生理解释 |
| 留出受试者测试 | 完全不参与任务微调的人上测检索 | 才能支持新受试者迁移；另需审查基础模型预训练重叠 |

身份探针仅在训练数据拟合，标准化/PCA也在训练折拟合；各受试者图片集合、样本数尽量匹配。同图标签相同使当前任务能合理混合，不应跨不同图片随意平均并保留一个硬标签。

若跨人mix改善检索且身份探针降低，可作为减少身份相关干扰的支持证据，但不是因果定论；如果探针不变而检索提高，仍可能是降噪/一般正则化；如果身份探针降低而检索也降低，则可能连有效信息一起抹掉。

**十二、论文评估和统计报告要求**

当前结果只报告点估计和百分点差，没有计算p值或置信区间。推荐正式流程：

- 从原训练图片中划分固定、按图片互斥的验证集，所有受试者共用同一图片划分。先在验证集选模型；最终测试一次。已经反复查看的公开200图仍标为开发基准，需要额外未用于开发的留出数据支持泛化结论。
- 预先指定一个主要指标，例如clean聚合Top5，并同时报告clean单试次Top1/5及聚合Top1。两数据集各自报告，平均值只能作为额外汇总。
- raw/EMA采用相同选择规则和预算；提供同epoch配对与各自验证集选择两种结果，不只展示有利的某一轮。
- 至少记录完整模型训练seed，报告每seed结果和均值/标准差。不要把恢复头seed当成独立encoder训练seed，不把三个抽样seed当成三次训练。
- 推断以配对差值为主。试次共享受试者和图片，不把几十万试次当成独立样本。用受试者与图片的交叉分组重采样或明确的混合效应建模；报告训练seed变动。10/20个受试者和3个训练seed仍有限，不能保证结论稳定。
- 若比较多个增强、指标和模型，先限定主要对照；其他结果标探索性，避免只挑显著的一项。需要显著性检验时再执行适当校正，不事后补写数值。
- 公布每组样本曝光量、更新数、GPU小时、停止轮次、模型/缓存hash和测试候选数。
