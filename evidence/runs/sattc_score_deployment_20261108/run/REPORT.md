# 固定 REVE 模型的 SATTC 与 SCORE 部署对照

本实验比较 S1、S2 的固定无身份监督与身份监督 checkpoint。保留原投影头、各自图像 adapter 和 EEG 预处理；只在检索时校准。

每位受试者的全部单试次测试预测和相同的 200 张候选图片用于无标签校准。算法不接收图片标签或试次分组，标签只在输出分数后用于计分。两模型候选图片相同，但冻结图像 adapter 不同，所以候选向量不同。

本表的聚合方式是同人同图全部有效试次的最终候选分数取均值。原始点积时，这与先平均原始预测再检索等价；加入候选相关校准或逐试次归一化后，不再等价。SATTC、SCORE 结果因此单列为分数聚合。

使用整批无标签测试 EEG 的实验属于传导式测试时校准，与此前只使用独立校准 EEG 的适配实验分开。论文原始 EEG 预处理、重复试次平均和源模型训练均未替换；这里验证部署算法在当前 REVE 系统上的作用。

单位为百分比，每格为 Top-1／Top-5。raw_dot 为原系统，raw_cosine 用于检查逐试次归一化本身的影响。

## 结果分析

四个固定模型均完成 SATTC 与 SCORE 的各阶段测试，没有数值失败或跳过旋转。56 份分数矩阵已由独立脚本重算，四项指标全部吻合；原始零步指标复现历史记录。正式计算耗时约 28.7 秒，使用已有冻结特征，未进行网络训练或 GPU 推理。

SATTC 白化对 S2 的聚合检索帮助较大。无身份监督模型的聚合 Top-5 从 27.0% 提高到 61.0%，身份模型从 29.0% 提高到 58.5%。但两者单试次 Top-5 分别从 13.90% 降到 8.61%、从 13.69% 降到 8.11%。因此，结果支持白化改善这两个系统的聚合检索，不能概括为所有推理指标提高。几何校正与完整融合没有继续超过白化后的聚合成绩。

S1 的白化收益较小，无身份监督／身份模型的聚合 Top-5 分别从 64.0%／57.5% 变为 65.0%／62.0%。直接在原始余弦分数上使用固定 k=10 的 CSLS，则达到 75.5%／69.5%。这个对照说明，S1 可以通过候选相似度校正改善检索，不需要先拟合坐标旋转；这一规律在 S2 上没有重复出现。

SCORE 的下降首先发生在矩匹配阶段。S1 无身份监督／身份模型的聚合 Top-5 均降至 19.0%；加入 CSLS、伪配对和正交恢复后的最终结果为 30.5%／33.0%。S2 的最终结果为 27.5%／30.5%，只比各自原系统高 0.5／1.5 个百分点。SCORE 最终身份模型比无身份模型高 2.5／3.0 个百分点，但 S1 绝对成绩明显下降，这不构成实用的稳定适配优势。

四组都从互近邻中选出了 160 对伪配对，数量满足恢复要求。事后用真实标签检查，S1 无身份监督／身份模型分别只有 18／17 对正确，S2 分别为 19／16 对，即正确率为 11.25%／10.63%、11.88%／10.00%。真实标签未参与配对筛选或拟合。当前证据表明伪配对质量低，身份模型也没有提供更可靠的对应；不能把此次结果解释为有了更集中的身份表征，就能直接恢复新受试者的坐标。矩匹配的影响、单试次噪声、原生 adapter 的几何结构，以及与论文训练和评估协议的差别，仍可能共同影响结果。

本轮没有继续搜索参数或更换 checkpoint。当前更值得保留的是白化与简单 CSLS 两项对照。若继续 SCORE，需要先明确提高伪配对可靠性的实验，而不是直接增加旋转或恢复网络容量。

## 复现范围与来源

SATTC 使用[作者仓库](https://github.com/QunjieHuang/SATTC-CVPR2026)固定 commit 的计算函数，三组测试与作者整段后处理流程逐元素一致。SCORE 按[公开 v1 的部署公式 3—9](https://arxiv.org/html/2608.19134v1)实现，公开材料未写清的数值保护和配对截断规则已固定记录。两项均为部署流程接入现有 REVE，未执行论文的源模型训练。SCORE 的 recovery-aware 训练也未加入这次固定模型对照。

本次向方法提供全部单试次预测，先校准再按图片平均候选得分。论文 THINGS 设置包含重复 EEG 先平均再编码的流程；本轮结果不能当作对论文原表的数值复现。无标签校准仍需候选图像库，因此它与比赛只接收 EEG、输出 1536 维向量的部署接口不同。
