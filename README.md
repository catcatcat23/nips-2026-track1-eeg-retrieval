## 当前模型与有效配置

```text
EEG（THINGS 63通道／Alljoined 32通道，使用各自电极坐标）
  → 固定预处理 → REVE → 池化512维 → 投影1536维 h
                                   ├→ blur 对齐
                                   └→ 恢复头 → clean 检索输出
训练图像 → 多尺度模糊 → 冻结DINOv2缓存 → 图像adapter → blur目标
```

主线训练使用 clean＋blur 对比监督、Local OT、同人同图试次混合、少量通道遮挡和 EMA。试次混合按50％单试次、25％两次平均、25％四次平均采样；测试关闭增强。详细实际参数见 `configs/` 与对应 run，不能以代码默认值替代运行值。

| 代表性配置 | 数据与用途 | clean 单试次 Top-1／5 | clean 聚合 Top-1／5 | blur 单试次 Top-1／5 | blur 聚合 Top-1／5 |
|---|---|---|---|---|---|
| v64 ep14 EMA .9998 | THINGS 单独训练 | 18.81／43.89 | 70.45／94.90 | 21.51／48.15 | 88.75／99.00 |
| v67 ep8 EMA .9998 | Alljoined 单独训练 | 3.64／12.83 | 27.57／56.65 | 3.90／13.36 | 40.30／70.30 |
| v69 ep15 EMA .9998 | 联合模型，测试THINGS | 18.75／43.66 | 71.70／94.05 | 21.51／48.10 | 87.20／99.25 |
| v69 ep15 EMA .9998 | 同一联合模型，测试Alljoined | 3.74／12.95 | 29.00／58.73 | 3.93／13.48 | 36.78／69.17 |

单位为％。这是代表性 checkpoint，不是等预算因果对照或隐藏测试排行榜。聚合是同人同图全部有效试次先推理、再平均原始预测。blur 和 clean 使用不同候选特征空间。公开测试被用于部分历史实验的模型选择，结果应按开发集表现理解。

默认可复现包仍保留原先验证过的 v64 提交来源（ep9 EMA .999）；表中 ep14 不会自动替换默认提交权重。旧 v39b 二阶段版本可从 Git 历史 `74e8732` 查看。

## 目前研究进度

试次混合与 EMA 带来最清楚的改善。身份监督增强了受试者可辨识性，但图片检索和新受试者少标签适配未出现稳定增益。LoRA、残差适配、统计对齐、Ridge 和传导式校正的结果已保留，避免重复尝试。

v92 同图跨人 EEG 对比监督已结束，未超过匹配轮次 v64。v93 单条 EEG 校准实验已结束：在一个新人上学出的修正，迁移到另一个新人时性能下降。v93 曾出现报告哈希字段错误，已经修复；当前应读取 `calibration_report`，不要把旧报告的“无效”理解为训练失败。

整理时本项目没有在运行的训练任务。没有启动新的训练，也没有自动恢复用户暂停的 LOSO 折。

## 复现与继续开发

1. 阅读 [AGENTS.md](AGENTS.md) 和 [STORAGE_POLICY.md](STORAGE_POLICY.md)。数据、缓存、权重和输出只能写入数据盘。
2. 安装记录的依赖，配置本机资产路径；运行 `python run.py --help`。原始缓存和 checkpoint 不随 Git 发布，需要向项目持有人取得。
3. 使用 [基线说明](docs/BASELINE_V64_V67.md) 的 `check`、`preflight`、`train`、`evaluate` 流程，并显式指定数据盘输出目录。
4. 后续研究脚本按原目录结构保存，部分含本机绝对路径。迁移前先检查对应 config 与源码快照，不要直接批量运行历史 launcher。
5. 新实验需先记录改动、对照、支持集／测试集隔离、模型选择规则、预算和种子。读出层、指标空间、聚合方式必须一致。

所有数字都应回到 `evidence/runs/` 核对。历史文档中的“正在运行”是当时状态，以当前交接文档和最后一条原始记录为准。清理只删除冗余权重，不删除负结果证据。数据与权重的许可独立于代码，来源说明见 [NOTICE.md](NOTICE.md)。
